## ▶️ How to Run

1. Install the [Dart SDK](https://dart.dev/get-dart)
2. Clone the repo:

```bash
git clone https://github.com/MohammadSamara9/dart-learning.git
cd dart-learning
```

3. Run any file:

```bash
dart run 03-projects/SimpleQuizApp.dart
```
